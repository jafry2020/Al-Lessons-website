      The big three vision foundation models in 2026:

      **CLIP / SigLIP** (OpenAI 2021; Google 2023 for SigLIP). Trained on image-caption pairs with contrastive loss. Output: aligned image + text embeddings.

## The three foundation models you'll actually use

In 2026, three pretrained vision models do a lot of heavy lifting:

**CLIP / SigLIP** — aligned image and text embeddings.

- Image → vector; text → vector; cosine similarity tells you how related they are.
- Powers: zero-shot classification, image-text retrieval, content moderation, multimodal search.
- Where it fails: dense prediction (segmentation, detection); fine-grained recognition.

**DINOv2** — self-supervised visual features.

- ViT trained without labels, with self-distillation.
- Produces strong feature vectors per image patch.
- Powers: feature extraction, fine-tuning starting point, clustering, dense correspondence.
- The new "default backbone" — better than ImageNet-pretrained ConvNets for many tasks.

**SAM / SAM 2** — promptable segmentation.

- Given image + a point / box / mask prompt, output a high-quality segmentation mask.
- Zero-shot — works on anything without training on your data.
- Powers: annotation tools (mask anything), interactive editing, automated pipelines.
- Often used as a building block in larger systems.

VLMs (LLaVA, GPT-4V, Claude vision, Gemini) are the fourth pillar but covered specifically in A7.6.

## CNN vs ViT: still both, depending

The internet sometimes acts like ViT replaced CNN. It didn't. Both are used heavily in production. The decision:

| Dimension                                 | CNN (ConvNeXt, EfficientNet, MobileNet) | ViT                      |
| ----------------------------------------- | --------------------------------------- | ------------------------ |
| Small data (&lt;10k images)               | Wins                                    | Underperforms            |
| Large data (>100k) or pretrained backbone | Strong                                  | Often wins               |
| Edge / mobile inference                   | Wins                                    | Heavier                  |
| Real-time detection (>30 FPS)             | YOLO (CNN-based)                        | Slower                   |
| Foundation model backbones                | Limited                                 | DINOv2, SigLIP, MAE      |
| Pretrained quality                        | Good (ImageNet, JFT)                    | Excellent (CLIP, DINOv2) |
| Inductive bias for translation invariance | Yes (helpful for medical, satellite)    | No (must learn)          |

A safe default in 2026: pretrained ConvNeXt-Base or DINOv2 ViT-B, fine-tune. Both work well, well-supported, no surprises.

For deployment: ConvNeXt for edge; ViT when latency budget allows.

## What's faded

Things that used to be everywhere and aren't in 2026:

- **Hand-engineered features** (SIFT, HOG, SURF). Replaced by learned features.
- **From-scratch CNN training** (no ImageNet pretraining). Almost never the right choice.
- **R-CNN, Fast R-CNN, Faster R-CNN** as first detectors to learn. Modern intros start with YOLO or DETR.
- **VGG, AlexNet** as production models. Used in textbooks only.
- **GANs** as the default generator. Diffusion replaced them for image generation.
- **Manual non-maximum suppression** (NMS) by writing your own code. Libraries handle it.

These appear in old code bases and tutorials. Recognise them; don't reach for them.
