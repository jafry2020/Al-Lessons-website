  - question: "What's the difference between semantic, instance, and panoptic segmentation?"
    shortAnswer: |
      Semantic: each pixel gets one class label, no object instances ('car', 'road', 'sky'). Instance: each pixel labelled with class + instance ID ('car_1', 'car_2'). Panoptic: combines both — every pixel gets class + instance (stuff like 'sky' has no instance; things like 'car' have instances).
    detailed: |
      The three flavours:

      **Semantic segmentation**: pixel → class. All pixels of the same class merge.

      Image of two cars: both cars get the 'car' label; you can't tell them apart.

      **Instance segmentation**: pixel → (class, instance_id). Each object instance has its own mask.

      Same two cars: each gets a distinct mask. Useful for counting, tracking, manipulation.

      **Panoptic segmentation**: combines semantic + instance. Every pixel labelled with (class, instance_id). For "stuff" classes (sky, grass, road), instance_id is the same per class. For "thing" classes (car, person), each instance is distinct.

      Choice depends on use case:
      - Counting people in a crowd → instance.
      - Sky / horizon detection → semantic.
      - Full scene parsing (autonomous driving) → panoptic.

      Modern architectures (Mask2Former) handle all three with the same model.
    pitfalls:
      - "Don't confuse with 'object detection' (boxes) — segmentation produces pixel masks, which are more precise."

    detailed: |
      SAM architecture: image encoder (ViT) + prompt encoder + mask decoder. Trained on the SA-1B dataset (1.1 billion masks across 11M images).

      How to use:
      - **Input**: an image + a prompt (one or more points, a box, or a coarse mask).
      - **Output**: a high-quality segmentation mask for what was prompted.

      Game-changing for annotation:
      - Annotators click once → SAM produces the mask.
      - 10× speedup on segmentation labelling.
      - Powers tools like Label Studio, Roboflow, CVAT.

      Production uses:
      - **Annotation tools** (the original killer use case).
      - **Auto-segment everything in an image** ("mask everything mode").

  - question: "How do you evaluate segmentation?"
    shortAnswer: |
      Mean IoU (mIoU) across classes for semantic; mask AP for instance (similar to detection mAP but with mask IoU instead of box IoU). Per-class metrics for diagnosis. Avoid pixel accuracy — dominated by background.
    detailed: |
      **Semantic segmentation**:

      - **IoU per class**: |intersection| / |union| between predicted and ground-truth masks.
      - **Mean IoU (mIoU)**: average IoU across classes. Standard headline.
      - **Per-class IoU**: identify weak classes.
      - **Pixel accuracy**: useless on its own — 95% accuracy on a foreground task is "always predict background."

      **Instance segmentation**:

      - **Mask AP**: like detection mAP but matches masks via IoU.
      - **Mask AP@[0.5:0.95]**: COCO standard.
      - Same precision/recall analysis as detection.

      **Panoptic segmentation**:

      - **PQ (Panoptic Quality)**: combines segmentation quality (SQ) and recognition quality (RQ).
      - Per-class PQ for diagnosis.

      Standard benchmarks: COCO, Cityscapes, ADE20K. Numbers vary widely by dataset difficulty.

      Tools: `torchmetrics.JaccardIndex` for IoU; HuggingFace `evaluate.load("mean_iou")`; `pycocotools` for mask AP.
    pitfalls:
      - "IoU heavily penalises small mistakes on thin objects (poles, wires). Use boundary IoU or panoptic quality for these cases."
  - question: "When should you fine-tune vs. use SAM?"
    shortAnswer: |
      Use SAM for class-agnostic / zero-shot / interactive segmentation, or as an annotation tool. Fine-tune a Mask2Former when you need class-aware predictions for a fixed set of categories and have labelled data.
    detailed: |
      | Situation | Approach |
      | --------- | -------- |
      | Annotate a new dataset | Use SAM for click-based mask generation; speedup 10× |
      | Class-aware segmentation, fixed classes, labelled data | Fine-tune Mask2Former |
      | "Mask everything" pipeline | SAM in "mask everything" mode + downstream classifier |
      | Detect-then-segment | Detector (YOLO / DETR) + SAM for each box → cleaner masks |
      | Open-vocab segmentation | Grounded-SAM (Grounding DINO + SAM) |
      | Medical / specialised domain | Fine-tune U-Net or domain-pretrained Mask2Former |
      | Real-time semantic | SegFormer-small with TensorRT |
      | Real-time interactive | SAM 2 (designed for this) |

      Combined pattern: SAM for annotation → train Mask2Former for production inference.

      SAM alone often isn't enough for production — you need to *label* the masks, which means classifier on top or zero-shot CLIP.
    pitfalls:
      - "SAM's masks can be 'over-segmented' (multiple masks for one thing) or 'under-segmented'. Tune prompts for your use case."
  - question: "What's U-Net and why does it survive?"
    shortAnswer: |
      U-Net (Ronneberger et al., 2015) is the encoder-decoder with skip connections that dominates medical imaging. It's smaller, simpler, trains on less data than transformer alternatives — perfect for specialised domains with limited labelled data.
    detailed: |
      U-Net architecture: encoder (CNN downsampling) → bottleneck → decoder (upsampling) with skip connections at each scale.

      Why it survives in 2026:
      - **Small data**: medical, satellite, microscopy often have &lt;1000 labelled images. U-Net trains; large transformers overfit.
      - **Domain-specific**: medical U-Nets are pretrained on medical data; transfer is excellent within the domain.
      - **Mature ecosystem**: nnU-Net (Isensee et al., 2021) is a self-configuring U-Net that handles dataset specifics automatically. Gold standard for medical segmentation.
      - **Compute-efficient**: ~10-40M parameters; runs on modest hardware.

      For general segmentation tasks (Cityscapes, ADE20K, COCO), Mask2Former / OneFormer beat U-Net. For medical / specialised, nnU-Net often still wins.

      Also: **U-Net is the backbone of diffusion models** (Stable Diffusion, FLUX). It denoises noisy images, predicting noise at each scale. Same architecture, different objective.

      For Track A purposes: U-Net is the right choice for small-data domain-specific segmentation; Mask2Former / SAM for everything else.
    pitfalls:
      - "Don't dismiss U-Net as 'old.' It's the standard in medical imaging in 2026 for good reasons (data scarcity, domain specificity)."

## Three flavours of segmentation

```
Original          Semantic          Instance          Panoptic
[2 cats]    →    [cat / bg]    →    [cat_1, cat_2]    →    [cat_1, cat_2, sky-stuff]
```

**Semantic**: every pixel gets one class label. Cars merge; sky is a region; no distinction between individuals.

**Instance**: every pixel gets a class AND an instance ID. Different cars distinguished; can count them.

**Panoptic**: combines both. "Things" (cars, people) get instance IDs; "stuff" (sky, grass) is treated as one region per class.

Which to use:

- Sky / road / horizon detection → semantic.
- Counting / tracking / per-object reasoning → instance.
- Full scene parsing → panoptic.

Most modern frameworks (Mask2Former, OneFormer) handle all three with one model.

## SAM: the annotation revolution

The Segment Anything Model (Meta, 2023; SAM 2 in 2024) is a foundation model for segmentation. Given:

- An image, and
- A prompt (point, box, or coarse mask),

it returns a high-quality segmentation mask for what was prompted.

The model:

```
Image → ViT image encoder → embedding
Prompt → prompt encoder → embedding
Decoder → mask
```

Trained on 1.1 billion masks across 11M images. The largest segmentation dataset ever.

Why it changed everything:

- **Annotation cost dropped 10×.** Annotators click once on an object; SAM produces the mask. Tools like Label Studio, Roboflow, CVAT all integrate SAM.
- **Zero-shot segmentation.** Works on anything — including domains SAM never saw — at decent quality.
- **Building block.** Detect with YOLO → segment each detected box with SAM. Cleaner masks than detection alone.

Important: **SAM is class-agnostic**. It produces masks but doesn't label them. For "is this a car?", combine with a classifier or CLIP zero-shot.

SAM 2 extends to video: track an object's mask through frames. Enables interactive video editing.

  SAM is like a precision laser-cutter for image regions. Point at any object, get a perfect
  outline. Doesn't know what the object is — that's a separate job. But the cutting itself is free,
  zero-shot, and works on almost anything.
</AnalogyCallout>

## The promptable paradigm

Promptable segmentation generalises beyond SAM:

**Grounding DINO + SAM (Grounded-SAM)**:

```
Text prompt "tractor in field" → Grounding DINO → bounding box(es)
                                            ↓
                                          SAM → high-quality mask(s)
```

Combined: open-vocabulary segmentation. Specify what to find with natural language; get pixel-precise masks.

**OneFormer**, **OneFormer**: training-time prompt about task (semantic / instance / panoptic) instead of training separate models.

In 2026 these promptable approaches are eating fixed-class segmentation for many use cases.

## Mask2Former: the general-purpose default

Mask2Former (Cheng et al., 2022) unified semantic, instance, and panoptic segmentation in one architecture:

- Transformer-based.
- Object queries (like DETR) but for masks instead of boxes.
- One pretrained checkpoint can fine-tune for any segmentation task.

HuggingFace usage:

```python
from transformers import Mask2FormerForUniversalSegmentation, Mask2FormerImageProcessor

processor = Mask2FormerImageProcessor.from_pretrained("facebook/mask2former-swin-large-coco-instance")
model = Mask2FormerForUniversalSegmentation.from_pretrained("facebook/mask2former-swin-large-coco-instance")

inputs = processor(images=image, return_tensors="pt")
outputs = model(**inputs)

# Post-process to masks
instance_seg = processor.post_process_instance_segmentation(outputs, target_sizes=[image.size[::-1]])[0]
```

Fine-tune on your data via standard HuggingFace Trainer or custom loop. Typically 10-50 epochs with low lr.

## Evaluation: mIoU and mask AP

**Semantic**: Mean IoU across classes.

```python
import torchmetrics
metric = torchmetrics.JaccardIndex(task="multiclass", num_classes=NUM_CLASSES, average="macro")
mIoU = metric(predictions, targets)
```

Per-class IoU is essential. mIoU of 0.5 could be (0.9, 0.1, 0.5) across three classes — one is great, one is broken.

**Instance**: Mask AP (analogous to box AP for detection).

```python
# Via pycocotools
from pycocotools.coco import COCO
from pycocotools.cocoeval import COCOeval
coco_eval = COCOeval(gt_coco, pred_coco, "segm")  # segm for mask
coco_eval.evaluate()
coco_eval.accumulate()
coco_eval.summarize()
```

mAP@[0.5:0.95] using mask IoU instead of box IoU.

**Panoptic**: Panoptic Quality (PQ) combines segmentation quality (SQ) and recognition quality (RQ).

Standard benchmarks:

| Dataset    | Task     | SOTA     |
| ---------- | -------- | -------- |
| Cityscapes | Semantic | mIoU ~85 |
| ADE20K     | Semantic | mIoU ~57 |
| COCO       | Instance | mAP ~55  |
| COCO       | Panoptic | PQ ~55   |

Domain-specific benchmarks vary wildly.

## Common failure modes

| Symptom                                      | Likely cause                   | Fix                                                 |
| -------------------------------------------- | ------------------------------ | --------------------------------------------------- |
| mIoU good overall, terrible on small classes | Class imbalance + IoU's nature | Class-balanced loss; focal loss                     |
| Fuzzy mask edges                             | Boundary modeling weak         | Boundary-aware loss (Dice + boundary); post-process |
| Holes in masks                               | Insufficient receptive field   | Larger encoder; dilated convolutions                |
| Fragmented small objects                     | Single-scale processing        | Multi-scale features (FPN, ASPP)                    |
| Inconsistent across frames (video)           | Per-frame processing           | Temporal smoothing; SAM 2 for video                 |
| Production worse than benchmark              | Distribution shift             | Production-augmented training                       |

For real-time segmentation:

| Approach                         | Latency             | Quality              |

For real-time: SegFormer or Mask2Former with smaller backbone + TensorRT. For interactive annotation: SAM (mobile / lightweight variants exist).

## Domain-specific: medical and satellite

For specialised domains:

- **Medical** (CT, MRI, histopathology, microscopy): nnU-Net is the gold standard. Self-configuring; handles dataset-specific preprocessing automatically. Often pretrained on domain-specific data (e.g., MONAI for medical).
- **Satellite / aerial**: U-Net or DeepLab variants; pretraining on aerial datasets (xView, SpaceNet) matters.
- **Microscopy**: U-Net dominates; Cellpose for cell segmentation specifically.

These domains have smaller data (often &lt;1000 images), specialised input characteristics (multi-channel, non-RGB), and require domain expertise in preprocessing.

## Closing for segmentation

Segmentation in 2026 has settled into: Mask2Former for general purpose, nnU-Net for medical / specialised, SAM 2 for promptable / annotation. The promptable paradigm (SAM, Grounded-SAM, Grounding DINO + SAM) is increasingly the way to handle open-vocabulary or label-scarce tasks.
